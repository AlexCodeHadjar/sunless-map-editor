# План работ — Редактор карт SunLess

Основа — ТЗ «Редактор карт SunLess» v1.0 (05.10.2026) и руководство «Карта главы SunLess».
Технология — Godot 4.7 (тот же движок, что игра): шейдеры воды и тумана игры, предпросмотр как в игре.
Дополнительно (просьбы владельца 05.10): интерфейс дружелюбный — без «сырых» чисел, расчёты под капотом;
агентский интерфейс по методике [CLI-Anything](https://github.com/HKUDS/CLI-Anything), чтобы ИИ-агент мог работать с редактором.
